Shared helpers, hooks, and admin UI building blocks used across [Sensinum](https://www.sensinum.com) Strapi plugins.

## Requirements

- Node.js `>=22.0.0 <=26.x.x`
- Yarn 4 (see `packageManager` in `package.json`)

## Install

```bash
yarn add @sensinum/strapi-utils
```

## Development

```bash
yarn install
yarn build
yarn test
```
